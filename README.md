# Cursor for AI Studio

A sandbox repository for the AI Studio team to explore and experiment with [Cursor](https://www.cursor.com/) features — including AI-assisted code generation, agent workflows, MCP integrations, and more.

## What This Repo Is For

Use this repo as a low-stakes playground to:

- **Try Cursor features** — Test agent mode, plan mode, inline editing, multi-file generation, and other capabilities in a safe environment.
- **Experiment with prompts** — Iterate on prompt strategies, rules, and skills to see what works best for our workflows.
- **Prototype ideas** — Quickly scaffold small projects, scripts, or proof-of-concepts without worrying about breaking anything.
- **Share learnings** — Document findings, patterns, and tips that the team can reference.

## Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/heather-w-wells/cursor-for-ai-studio.git
   ```
2. Open in Cursor:
   ```bash
   cursor cursor-for-ai-studio
   ```
3. Start experimenting! Create a branch for anything you'd like to try.

## Guidelines

- **Branch freely** — Create branches for experiments. Keep `main` clean.
- **No secrets** — Do not commit API keys, credentials, or sensitive data.
- **Temporary by nature** — This repo is a scratchpad. Don't rely on it for production work.
